# 🌿 Plant Disease Detection

This project uses deep learning to identify plant diseases from leaf images.

## 📁 Dataset

The dataset contains ~28,000 `.jpg` images, now compressed into a single ZIP file for easy download.

🔗 [Download Full Dataset from Google Drive](https://drive.google.com/file/d/1NjoXJAREOmVth5EGjN6-Ewe-V6xbpU88/view?usp=sharing)

After downloading, extract the zip and place the dataset folder in your project directory.
